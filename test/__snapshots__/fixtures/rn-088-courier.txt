How to fix

[A]      Let this text scale
         1. Remove allowFontScaling={false}; if the text truly cannot grow (a tab bar label), keep
            it and make sure its meaning is available another way.
         2. Let the container grow with the text: no fixed height, numberOfLines only where the full
            text is shown elsewhere.
         https://github.com/muhittincamdali/a11ylabel/blob/main/docs/guides/larger-text.md#react-native-and-expo

[B]      Raise the limit to 2 or remove it
         1. Set maxFontSizeMultiplier to 2 or more, or to 0 for no limit.
         2. Keep a lower limit only on repeated navigation such as a tab bar.
         https://github.com/muhittincamdali/a11ylabel/blob/main/docs/guides/larger-text.md#react-native-and-expo

[C]      Stop forcing the light scheme
         1. Remove Appearance.setColorScheme('light'), or call it only with the person's own choice.
         2. Read useColorScheme() and pick colours for both schemes.
         https://github.com/muhittincamdali/a11ylabel/blob/main/docs/guides/dark-interface.md#react-native

[D]      Read Reduce Motion and calm the animation
         1. Read AccessibilityInfo.isReduceMotionEnabled() and listen to its reduceMotionChanged
            event (or use Reanimated's useReducedMotion()).
         2. When it is on, do not start Animated.loop, auto-playing Lottie or carousel motion; show
            the final frame instead.
         https://github.com/muhittincamdali/a11ylabel/blob/main/docs/guides/reduced-motion.md#react-native-and-expo

[E]      Name the button
         1. Add accessibilityLabel="Close" (or aria-label) and accessibilityRole="button" to the
            Pressable or Touchable.
         2. For react-native-paper's IconButton, pass accessibilityLabel.
         https://github.com/muhittincamdali/a11ylabel/blob/main/docs/guides/voiceover.md#react-native-and-expo

[F]      Drop the control type from the label
         1. Shorten the label to the action ("Close") and set accessibilityRole="button" (or
            role="button").
         https://github.com/muhittincamdali/a11ylabel/blob/main/docs/guides/voiceover.md#react-native-and-expo
