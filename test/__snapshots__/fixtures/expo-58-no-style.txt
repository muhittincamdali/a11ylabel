ERROR    A11Y201 Light appearance forced for the whole app · Dark Interface
         app.json
         app.json does not set userInterfaceStyle, so Expo uses light: the app ignores Dark Mode and
         nothing in the code turns it dark.
         Fix: [A] Set userInterfaceStyle to automatic

How to fix

[A]      Set userInterfaceStyle to automatic
         1. In app.json (or app.config), set "userInterfaceStyle": "automatic"; Expo uses light when
            the key is missing.
         2. On Android, install expo-system-ui for the setting to apply there too.
         3. Read the scheme with useColorScheme() and give every screen dark colours.
         https://github.com/muhittincamdali/a11ylabel/blob/main/docs/guides/dark-interface.md#expo
