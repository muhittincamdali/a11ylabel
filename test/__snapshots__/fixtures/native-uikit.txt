How to fix

[A]      Remove the content size limit from the window
         1. Remove maximumContentSizeCategory from the window, or set it to .accessibilityExtraLarge
            (AX3) or larger.
         2. Limit only views that cannot grow and offer the Large Content Viewer for them
            (UILargeContentViewerInteraction).
         3. Check the common tasks at the largest accessibility size.
         https://github.com/muhittincamdali/a11ylabel/blob/main/docs/guides/larger-text.md#uikit

[B]      Let this label follow Dynamic Type
         1. Set adjustsFontForContentSizeCategory = true.
         2. Give the label a font from UIFont.preferredFont(forTextStyle:) or
            UIFontMetrics(forTextStyle:).scaledFont(for:), which that property needs to take effect.
         3. Set numberOfLines = 0 so the text wraps.
         https://github.com/muhittincamdali/a11ylabel/blob/main/docs/guides/larger-text.md#uikit

[C]      Scale the font with UIFontMetrics
         1. Wrap the font: UIFontMetrics(forTextStyle: .body).scaledFont(for: font), or use
            UIFont.preferredFont(forTextStyle:).
         2. Set adjustsFontForContentSizeCategory = true on the label, text field or text view.
         https://github.com/muhittincamdali/a11ylabel/blob/main/docs/guides/larger-text.md#uikit

[D]      Read Reduce Motion and calm the animation
         1. Check UIAccessibility.isReduceMotionEnabled before starting the animation, and observe
            UIAccessibility.reduceMotionStatusDidChangeNotification.
         2. When it is on, skip parallax (UIInterpolatingMotionEffect) and endless animations, or
            replace them with a cross-fade.
         https://github.com/muhittincamdali/a11ylabel/blob/main/docs/guides/reduced-motion.md#swiftui-and-uikit

[E]      Name the button
         1. Set button.accessibilityLabel = "Close" (for a UIBarButtonItem,
            item.accessibilityLabel).
         2. For a system action, prefer UIBarButtonItem(systemItem:), which comes with a localized
            label.
         https://github.com/muhittincamdali/a11ylabel/blob/main/docs/guides/voiceover.md#uikit

[F]      Check the in-app dark mode
         1. Turn on the app's dark setting and use the common tasks: launch, sign-in, purchase and
            settings must stay dark.
         2. Consider following the system appearance by default, so people who use Dark Mode do not
            have to find the setting.
         https://github.com/muhittincamdali/a11ylabel/blob/main/docs/guides/dark-interface.md#an-in-app-setting

[G]      Drop the control type from the label
         1. Shorten the label to the action ("Close"); set accessibilityTraits = .button on custom
            controls.
         https://github.com/muhittincamdali/a11ylabel/blob/main/docs/guides/voiceover.md#uikit

[H]      Check the media, then decide on the two labels
         1. List the videos of the common tasks and check each for a captions track and a
            described-audio track.
         2. With AVPlayerViewController, the system shows legible and audio options when the asset
            has them.
         https://github.com/muhittincamdali/a11ylabel/blob/main/docs/guides/contrast-color-media.md#captions-and-audio-descriptions
