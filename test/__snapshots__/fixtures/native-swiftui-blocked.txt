How to fix

[A]      Remove the Dynamic Type limit from the scene
         1. Remove .dynamicTypeSize(…) from the WindowGroup content, or raise its upper bound to
            .accessibility3 or above (AX3 is the first size above 200% for body text).
         2. Put a limit only on the views that cannot grow, such as a tab bar, and give them
            .accessibilityShowsLargeContentViewer().
         3. Preview the screens with .dynamicTypeSize(.accessibility5).
         https://github.com/muhittincamdali/a11ylabel/blob/main/docs/guides/larger-text.md#swiftui

[B]      Remove the build setting that forces light
         1. Delete INFOPLIST_KEY_UIUserInterfaceStyle (Build Settings > Info.plist Values > User
            Interface Style), or set it to Automatic.
         2. Give every custom colour a dark variant in the asset catalog, then use the common tasks
            in Dark Mode.
         https://github.com/muhittincamdali/a11ylabel/blob/main/docs/guides/dark-interface.md#infoplist-and-build-settings

[C]      Use a text style, or a size relative to one
         1. Replace .system(size: 17) with a text style such as .body, .headline or .title.
         2. For a custom size or font, use .system(size: 17, …) only for decoration; for text, use
            Font.custom("Name", size: 17, relativeTo: .body) or a @ScaledMetric size.
         https://github.com/muhittincamdali/a11ylabel/blob/main/docs/guides/larger-text.md#swiftui

[D]      Read Reduce Motion and calm the animation
         1. Add @Environment(\.accessibilityReduceMotion) var reduceMotion to the view.
         2. When it is true, drop repeatForever, rotation and 3D effects, or replace them with a
            fade.
         https://github.com/muhittincamdali/a11ylabel/blob/main/docs/guides/reduced-motion.md#swiftui-and-uikit

[E]      Name the button
         1. Use Label("Close", systemImage: "xmark").labelStyle(.iconOnly) as the button's label, or
            add .accessibilityLabel("Close").
         2. Name the action, not the control: "Close", not "Close button" or "X".
         https://github.com/muhittincamdali/a11ylabel/blob/main/docs/guides/voiceover.md#swiftui

[F]      Add a dark value to each colour
         1. Select the colour set in Xcode, set Appearances to "Any, Dark" in the Attributes
            inspector and fill the Dark well.
         2. Keep a single value only for colours that read well on both light and dark backgrounds.
         https://github.com/muhittincamdali/a11ylabel/blob/main/docs/guides/dark-interface.md#asset-catalog-colours

[G]      Drop the control type from the label
         1. Shorten the label to the action ("Close"); add .accessibilityAddTraits(.isButton) where
            the view is not already a Button.
         https://github.com/muhittincamdali/a11ylabel/blob/main/docs/guides/voiceover.md#swiftui

[H]      Check the contrast, then add high contrast values where needed
         1. Measure text and control colours against their backgrounds (about 4.5:1 for most text).
         2. Where the default falls short, tick High Contrast in the colour set's Attributes
            inspector and fill the new wells with stronger values.
         https://github.com/muhittincamdali/a11ylabel/blob/main/docs/guides/contrast-color-media.md#sufficient-contrast

[I]      Check the media, then decide on the two labels
         1. List the videos of the common tasks and check each for a captions track and a
            described-audio track.
         2. With AVPlayerViewController or VideoPlayer, the system shows legible and audio options
            when the asset has them.
         https://github.com/muhittincamdali/a11ylabel/blob/main/docs/guides/contrast-color-media.md#captions-and-audio-descriptions
